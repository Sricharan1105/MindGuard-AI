## 🚀 Quick Start

Prerequisites:
- Node.js 20+
- Python 3.11+
- AWS Account (free tier works)
- Twilio Account (free trial works)
- Git

Installation (5 steps):

Step 1: Clone
git clone https://github.com/Sricharan1105/MindGuard-AI.git
cd MindGuard-AI

Step 2: Frontend setup
cd frontend
npm install
cp .env.example .env

Step 3: Backend setup
cd ../backend
npm install
cp .env.example .env

Step 4: ML Model setup
cd ../ml-model
pip install -r requirements.txt
cp .env.example .env

Step 5: Run everything
# Terminal 1 - Frontend
cd frontend && npm run dev

# Terminal 2 - Backend
cd backend && npm run dev

# Terminal 3 - ML Model
cd ml-model && python main.py

Open: http://localhost:3000
